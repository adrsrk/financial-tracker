# 💸 Personal Financial Tracker

Простое веб-приложение для отслеживания личных доходов и расходов. Помогает контролировать бюджет, анализировать траты и достигать финансовых целей.

## 🔧 Стек технологий

- Java 17
- Spring Boot
- PostgreSQL
- JPA / Hibernate
- REST API
- Lombok
- Flyway
- Swagger (OpenAPI)
- Maven / Gradle

## 🚀 Функциональность

- ✅ Регистрация и авторизация пользователей
- 💰 Учет доходов и расходов
- 📊 Категории трат
- 🧾 История операций
- 📅 Ежемесячная статистика
- 🛠️ API для интеграции с фронтом
- (Optional) 📈 Графики и аналитика
